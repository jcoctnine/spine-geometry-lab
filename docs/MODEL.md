# 模型、角度约定与边界

本文描述 `dist/cobb.html` 的实际实现。代码与所有坐标均为合成教学示意。

## 1. 中心线

屏幕坐标向右为 x 正方向、向下为 y 正方向，参数 t 从头侧到尾侧取值于 [0, 1]：

```text
x(t) = x₀ + A cos(2πt)
y(t) = y₀ + Ht
A = H tan(β) / (2π)
q(t) = dx/dy = −tan(β) sin(2πt)
```

β 为滑块设置的最大切线倾角，范围 0–32°；使用三角函数时须换算为弧度。代码中 H=520，x₀=245，y₀=62。

把切线相对竖直向下的角度记作 θ，并约定偏右为正：

```text
θ(t) = atan(q(t))
κ(t) = dθ/ds = (d²x/dy²) / [1 + (dx/dy)²]^(3/2)
```

κ 的符号采用上述方向约定。非零幅度时，κ 在 t=0.25 和 t=0.75 变号；t=0.5 处侧向位移达到极值，切线倾角为 0°，但不是曲率变号点。

当 β=0 时，整条中心线为直线：κ 处处为 0，但没有曲率变号点。程序因此隐藏两处变号标记。

## 2. 模拟椎体与终板

17 枚椎体中心均匀取样于 t=i/16（i=0…16），仅为便于识别而依次标注 T1–T12、L1–L5。其间距、形状和标签不构成解剖学重建。

默认终板垂直于中心线切线。终板相对屏幕水平线的角度 α 以顺时针为正：

```text
αbase(t) = −θ(t)
αᵢ = αbase(tᵢ) + δᵢ
Nᵢ = (cos αᵢ, sin αᵢ)        # 向右的终板单位方向
Vᵢ = (−sin αᵢ, cos αᵢ)       # 椎体内向下的单位方向
```

δᵢ 是“进阶”设置中的椎体方向偏移，范围 ±12°。偏移会旋转对应的整个矩形，中心线及椎体中心不移动；它不是对真实楔形椎或三维旋转的完整模拟。

矩形宽 w=48，高 h=18，角点为 `cᵢ ± wNᵢ/2 ± hVᵢ/2`。选中上端椎 u 和下端椎 l 后，测量终板经过：

```text
Pupper = cᵤ − hVᵤ/2          # 上端椎的上终板
Plower = cₗ + hVₗ/2          # 下端椎的下终板
```

上下终板线段分别沿 Nᵤ、Nₗ 延伸；程序要求 u<l，禁止同一椎体或顺序颠倒。

## 3. 两种角度

```text
Cobb = |αₗ − αᵤ|
中心线切向差 = |θ(tₗ) − θ(tᵤ)|
```

所有角度以度显示。默认所选两端的 δ 都为 0，此时两种角度相同。改变终板方向偏移后，两种角度可不同，也可能恰好仍相同。

界面右侧小图将两个终板方向平移到同一原点，不改变方向与夹角；它不表示两条原始延长线的实际交点。SVG 等比例缩放，避免显示角度受横纵缩放比例影响。

模型中 |α|≤44°，所选夹角≤88°，因此直接角差没有超过90°时的角度选择歧义。不能将此实现直接推广为覆盖所有严重侧弯的临床 Cobb 算法；也不能对任意临床角度简单套用 `acos(|dot|)`，以免将钝角折成其补角。

“选择模型中夹角最大的组合”遍历当前模型中的所有有序椎体组合并选取最大终板角差。这只是教学操作，未进行主弯识别或临床端椎判定。

## 5. 科学解释边界

中心线的曲率变号点、侧向位移极值、临床 Cobb 端椎与手术固定椎是不同概念。理想模型中终板方向与中心线法线一致，并不证明真实影像中二者严格一致。

本工具不处理 X 线影像，不含分割模型，也未进行临床验证。请将其用于概念讲解和软件开发讨论，不将合成读数作为患者结果或研究实验数据。
